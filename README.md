# KredoKash Website Prototype

Self-contained responsive HTML prototype based on the supplied visual reference.

## Run
Open `index.html` in a browser.

## Included
- Responsive fintech landing page
- KredoKash financing positioning
- Working capital, invoice finance, import finance and asset finance
- Financing selector / indicative calculator
- 10-step credit process
- Credit & risk section
- Credit intelligence section
- Institutional capital partner section
- FAQ accordion
- Financing application modal
- Mobile responsive layouts

The application form is intentionally a front-end prototype and should be connected to the production application/API before launch.
